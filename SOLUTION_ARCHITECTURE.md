# Solution Architecture

⚠️ **This file needs to be customized for your project.**

## Quick Setup

Run `/generate-architecture` or ask Claude to "analyze this project and create the architecture document".

Alternatively, copy the template from `.ai/templates/SOLUTION_ARCHITECTURE_TEMPLATE.md` and fill it in manually.

---

## Minimum Required Sections

1. **Overview** - What the project does
2. **Directory Structure** - Where files go
3. **File Placement Rules** - What goes where
4. **Naming Conventions** - How to name things
